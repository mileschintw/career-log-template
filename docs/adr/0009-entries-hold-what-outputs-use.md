# Entries hold what an output uses; perishable sources are excerpted

Consolidate's old goal was that any output could be written from the entry alone, so a sourced fact was never removed unless it was wrong. An entry for ongoing work then only grew: it copied detail its PRs and issues already hold, wrote the user's words twice (the original and a bracketed translation), and kept every earlier design as a change log. Every mode that reads the entry paid for that in context ([0004](0004-files-modes-read-hold-current-truth.md)).

So an entry now keeps a detail only when a resume line, an interview answer, or the first follow-up on either (why this way, how it works, what went wrong, what you would change) would use it or it supports one. Everything else is a link to a durable source. A first test that admitted the deepest follow-up let almost every detail through, since a follow-up can always go one level deeper. The test is the only limit: no size cap and no per-section shape. An entry for one phase holding only what belongs is expected to fit under the size check's threshold; one still over it likely covers more than one phase, which calls for a split rather than a deeper cut. Consolidate may delete superseded state, a detail that does not belong when its source is durable, and duplicates, and it may merge lines about one thread. Each merge stays inside one attribution category and one side of a conflict, and the user approves every merge and deletion in the diff. A source that will disappear, an agent session transcript above all, is excerpted into `sources/<agent>/` before a fact cites it, by a tool that extracts and redacts the turns the agent picks. The entry paraphrases the user's words in the record language and cites the excerpt, so the original wording stays recoverable without living in the entry. An excerpt is durable like any file in `sources/`, so a detail that does not belong and is cited to a session or to the user alone leaves the entry once an excerpt holds its words, the key staying as the link; it stays only when the user's words cannot be recovered.

The cost: an interview deep dive reaches below the entry, through its links, and its notes go into the application folder rather than back into the entry.
