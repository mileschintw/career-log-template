# A long experience splits into a series of flat entries

An entry for ongoing work keeps growing even when it holds only what an output uses ([0009](0009-entries-hold-what-outputs-use.md)), because a long project has several phases and each adds what belongs. Past what an agent's Read returns in one call, the modes that read an entry whole get only its first page; the size check's threshold sits at half of that. So consolidate splits an entry still over the size check's threshold once condensed, never before: condensing comes first, and a split is the remedy only for an entry that covers more than one phase. The user approves the cut points and the result.

A part is the unit a reader picks for one posting: a project within a long job, a phase within a long project. Each part stands alone (its own context, contribution, one line, period and tags), so each part reads on its own and fits in one Read. The parts are flat files beside every other entry, `entries/<YYYY-MM>-<slug>-<part>.md`, linked by `series: <slug>` in their front matter, with `<part>` naming the phase rather than numbering it, so the file name says what the part covers. The earliest part keeps the original path.

We considered a folder per series and rejected it: application folders are frozen once sent and `sources/` is never edited, so the paths they cite could not be rewritten, and a folder would record the series a second time beside `series:`. Keeping the earliest part at the original path is what lets those frozen references still resolve. The cost: a reference made before the split points at the earliest part even when the fact it cites now lives in a later one, and only the README, `stories.md` and `profile.md` pointers are updated.

The modes that select entries for a posting or a target (fit and write) still treat a series as one experience: a part that touches a requirement brings in every part, each read whole in its own Read, and each fact is cited by the part that holds it. A later part can hold what bears on an earlier one (a `Settled:` line, who owns the work now), and on a resume the series is one job or project. The split bounds each Read, not what a run reads in total.
