# The files modes read hold current truth, not history

Every mode that writes an output reads entries, `profile.md`, `direction.md` and `stories.md`, often in full, so anything kept there is paid for in context on every run. Usage history grows with each application rather than with each experience: once there are hundreds of applications, per-application pointer lines, kept log lines and the version lists of settled conflicts would outweigh the facts. They also duplicate records that already exist: each output's provenance table, git history, `sources/import-log.md` and `applications.md`. So those files are rewritten in place. Pending facts are deleted once placed, a settled conflict shrinks to one `Settled:` line (kept, because the write and review checks need the wrong wording to block it), and `## Past phrasings` is a short curated set rather than a record of use. The cost is that "where was this used?" is answered by searching the outputs and git, not by reading the entry.
